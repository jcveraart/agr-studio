Privacy & local data handling

Strava activity viewer

This is an independent personal local application. You register and control your own Strava developer application. OAuth reads only your authorized activity summaries: name, date, sport, moving time, distance and ascent. GPS tracks, health streams and other users’ data are not displayed.

Activity summaries are held in server memory for at most 30 seconds and displayed only in the isolated viewer. They are not saved in browser storage, exported, used for analytics, combined with planner data or sent to an AI provider. Strava may monitor API usage under its API policy.

Application credentials and OAuth tokens are stored in an AES-GCM encrypted file under .private-strava/. The encryption key is alongside it: someone with access to the entire folder can decrypt it. The folder is excluded from Git and project archives. Protect your device and this folder.

Disconnect revokes OAuth access and clears the local credentials and temporary activity cache. Forget local connection clears local data only; remove authorization separately in Strava My Apps. Revocation detected while loading data clears the local access tokens. A confirmation message reports deletion.

Training planner

The main planner stores your directly entered profile, workout feedback and routes in this browser. Local backups exclude Strava data and credentials. AI coaching is optional and requires consent for each request. It receives the planner context described in that form, never the Strava activity viewer’s data.

Route services

On explicit searches, PDOK receives the Dutch town name and Overpass receives the search area. On explicit route calculation, BRouter receives the chosen public segment and start coordinates. Do not use a private start address if you do not wish to share it with the routing service.
